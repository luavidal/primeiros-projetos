Envio de código para o GitHub

O processo de envio de código para o GitHub envolve os seguintes passos:

  1. Adicionar os arquivos ao stage: Use o comando git add . para adicionar todos os arquivos modificados ao stage, ou git add <nome_do_arquivo> para adicionar um arquivo específico.
  2. Fazer o commit: Use o comando git commit -m "Mensagem do commit" para criar um commit com uma mensagem descritiva do que foi alterado.
  3. Enviar para o repositório remoto: Use o comando git push origin <nome_da_branch> para enviar as alterações para a branch correspondente no GitHub.


Comandos úteis

  • git status: Verifica o status dos arquivos no repositório, mostrando quais estão modificados, quais estão no stage e quais não estão sendo rastreados.
  • git log: Exibe o histórico de commits do repositório, mostrando as mensagens de commit, os autores e as datas.
  • git diff: Mostra as diferenças entre os arquivos modificados e os arquivos no stage ou no último commit.

Utilize git pull para atualizar seu repositório local com as últimas alterações do repositório remoto. Utilize git commit para salvar suas alterações localmente.
